# Pretraining Data

`manifest.json` is generated by `scripts/download_pretrain_datasets.py` and
records the exact ModelScope repositories, shard paths, byte sizes, and SHA-256
metadata selected for the approximate 20-25B-token corpus.

Download or resume with:

```bash
.venv/bin/python scripts/download_pretrain_datasets.py --output datasets
```

The downloader uses ModelScope first and only selected shard paths, so it does
not fetch the complete 150B-token SkyPile repository. ModelScope downloads are
resumable through its local cache. The 55 GiB raw-text budget is intentionally
larger than 20 GiB because Chinese text tokenizes to fewer Qwen2.5 tokens per
UTF-8 byte. The exact count still depends on normalization; count tokens during
preprocessing before launching pretraining.
